# Sinan Robo · 开源具身模型推理基准 · 计划与预算（2026-09-16）

## 目标
做出全网第一份"开源具身模型（VLA）× 推理硬件"的实测表：每个模型在每张卡上的单步推理延迟 p50 / p95、吞吐（动作块/秒）、显存峰值、按实时租价折算的每千次推理成本。全部可复现：容器镜像、配置、原始日志、证据链接公开。

## 范围（第一批）
- **模型 14 个**（权重与推理代码都公开、能在 24GB 卡上跑 fp16/bf16）：OpenVLA-7B、Octo-base、π0、π0.5、SmolVLA、GR00T N1.7、GR00T N1.6、RDT-1B、CogACT-Base、SpatialVLA-4B、UniVLA-7B、MolmoAct-7B、X-VLA、NORA。第二批再加 LingBot-VLA、WALL-OSS、GO-1、InternVLA-M1、EO-1、MiniVLA、VLA-Adapter、Being-H0、RynnVLA（部分需要 40GB 以上显存或专用运行时）。
- **硬件 4 张（云租）**：RTX 4090 24GB、RTX 5090 32GB、A100 80GB、H100 80GB。这四张覆盖"实验室工作站 → 数据中心"的价格带，也是我们算力账本每天在报价的卡。
- **统一配置**：batch 1、图像 224 或模型默认、动作块 = 模型默认、bf16、50 步预热、500 步计时、同一段固定输入（图像 + 指令 + 状态），记录 p50 / p95 / 吞吐 / 显存峰值 / 驱动与库版本。

## 第一阶段进展（2026-09-18，RTX 4090，AutoDL 西北B区，bf16，batch 1）

| 模型 | 单步 p50 | p95 | 吞吐 | 显存峰值 | 备注 |
|---|---|---|---|---|---|
| NORA 3B | 112 ms | 127 ms | 8.7 步/秒 | 7.1 GB | 生成 16 个动作 token |
| OpenVLA-7B | 162 ms | 173 ms | 6.0 步/秒 | 14.4 GB | 7 个离散动作 token |
| SmolVLA 450M | 170 ms | 197 ms | 5.7 块/秒 | 0.9 GB | 每步产出 50 步动作块（flow matching 10 步去噪） |
| SpatialVLA-4B | 376 ms | 405 ms | 2.6 步/秒 | 7.8 GB | |
| MolmoAct-7B | 934 ms | 940 ms | 1.1 步/秒 | 16.3 GB | 生成 64 token（含推理轨迹） |

未能复现（如实记录）：π0 / π0.5 依赖 Google PaliGemma 分词器（受限仓库，镜像无法提供，需 HF 授权账号）；MiniVLA / VLA-Adapter 为 prismatic 格式，需各自项目运行时。第二批处理。

踩坑记录：pypi 用华为云镜像（其他镜像在该机房只有 KB/s）；hf-mirror 需 `HF_HUB_DISABLE_XET=1`；lerobot 0.6 分词在预处理流水线；MolmoAct 需对嵌套子配置逐个设 `_attn_implementation`；数据盘 50 GB 逐模型清权重。实际花费约 ¥15（8 小时 × ¥1.88）。

## RTX 5090 对照（2026-09-18，AutoDL 北京B区 ¥2.78/时，bf16，batch 1，torch 2.8+cu128）

| 模型 | 4090 p50 | 5090 p50 | 5090 相对 4090 | 每千次成本 4090（¥1.88/h） | 每千次成本 5090（¥2.78/h） |
|---|---|---|---|---|---|
| NORA 3B | 112 ms | 129 ms | 慢 15% | ¥0.06 | ¥0.10 |
| OpenVLA-7B | 162 ms | 146 ms | 快 10% | ¥0.08 | ¥0.11 |
| SmolVLA 450M | 170 ms | 166 ms | 快 3% | ¥0.09 | ¥0.13 |
| SpatialVLA-4B | 376 ms | 362 ms | 快 4% | ¥0.20 | ¥0.28 |
| MolmoAct-7B | 934 ms | 675 ms | 快 28% | ¥0.49 | ¥0.52 |

观察：batch 1 的单条推理吃的是单核时延与访存，不是算力；5090 只在生成长序列（MolmoAct 64 token）时明显更快。按每千次推理成本，五个模型在 4090 上都更便宜。两台机器 torch 版本不同（4090 用 2.5.1+cu124，5090 必须 2.8+cu128），版本差异是 NORA 变慢的可能原因之一，已如实记录在证据字段。

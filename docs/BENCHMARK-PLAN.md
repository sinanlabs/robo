# Sinan Robo · 开源具身模型推理基准 · 计划与预算（2026-09-16）

## 目标
做出全网第一份"开源具身模型（VLA）× 推理硬件"的实测表：每个模型在每张卡上的单步推理延迟 p50 / p95、吞吐（动作块/秒）、显存峰值、按实时租价折算的每千次推理成本。全部可复现：容器镜像、配置、原始日志、证据链接公开。

## 范围（第一批）
- **模型 14 个**（权重与推理代码都公开、能在 24GB 卡上跑 fp16/bf16）：OpenVLA-7B、Octo-base、π0、π0.5、SmolVLA、GR00T N1.7、GR00T N1.6、RDT-1B、CogACT-Base、SpatialVLA-4B、UniVLA-7B、MolmoAct-7B、X-VLA、NORA。第二批再加 LingBot-VLA、WALL-OSS、GO-1、InternVLA-M1、EO-1、MiniVLA、VLA-Adapter、Being-H0、RynnVLA（部分需要 40GB 以上显存或专用运行时）。
- **硬件 4 张（云租）**：RTX 4090 24GB、RTX 5090 32GB、A100 80GB、H100 80GB。这四张覆盖"实验室工作站 → 数据中心"的价格带，也是我们算力账本每天在报价的卡。
- **统一配置**：batch 1、图像 224 或模型默认、动作块 = 模型默认、bf16、50 步预热、500 步计时、同一段固定输入（图像 + 指令 + 状态），记录 p50 / p95 / 吞吐 / 显存峰值 / 驱动与库版本。

## 预算
**第一阶段（云租，必需）**
- 每次运行约 2 小时（拉权重、装环境、预热、计时）。56 次 ≈ 112 GPU 小时。
- 按算力账本 9 月 15 日 Vast.ai 按需中位价：4090 $0.47/h、5090 $0.54/h、A100 $0.72/h、H100 $3.00/h。
- 28 小时 × 每张卡 ≈ $13 + $15 + $20 + $84 = **约 $132**。
- 失败重跑、环境调试、权重下载的存储与带宽，按 2 倍留余量：**$300 以内，约 ¥2,200**。
- 之后每月增量（新模型 + 复测）：**约 ¥500 / 月**。

**第二阶段（边缘设备，建议）**
- 机器人真正跑模型的是车载 / 机载的 Jetson，不是 H100。这一栏是这份基准最有价值、也最没人做过的部分。
- NVIDIA Jetson AGX Thor 开发者套件：约 **¥25,000–30,000**（一次性，含税运）。预算紧可先买 Jetson AGX Orin 64GB 开发套件（约 ¥14,000），性能落后一代但仍是当前大量机器人的实际配置。
- 建议在第一阶段结果发布、看到引用与反馈后再决定。

**合计**：第一阶段 ¥2,200 起步、每月 ¥500；第二阶段一次性 ¥14,000–30,000。做到第一阶段，Robo 就有了别人没有的数据；做到第二阶段，就是行业基准。

> 起因：冰哥问思南能不能做世界模型研究。定调：思南只「测」不「做」——不训练模型、不买卡，做别人没有的独立测量。
> 和主业的关系：考题里放商家关心的题（产品转一圈会不会变形、门店走一遍会不会穿帮、包装字会不会糊），这些题都过了、价格也下来了，就是世界模型能接进导演梦想家的信号。

## 第一步：索引（已上线 2026-11-06）

- 页面：/world-models、/world-models/<id>（中英），导航「世界模型」；方法论第 8 节。
- 数据：`data/world_models.json`，字段与规则见文件 `_meta` 和 `scripts/validate.mjs`（每个确定字段必须有 evidence，否则构建失败；说明文字过禁用词）。
- 活性：`scripts/activity.py` 每天顺带抓世界模型的 GitHub / HF / 魔搭数字，单独存 `data/activity/world_*.json`，不混进 VLA 的周报月报统计。
- 加新模型：照 `_meta.fields` 填一条，跑 `npm run build`，validate 报的「无来源的确定值」必须清零。

## 第三步：司南实测

### A. 速度与显存（开源权重）

- 协议：官方推理脚本 + 官方默认采样步数；固定输入（同一张起始图、同一段控制序列）；生成 5 秒（或模型最小单位）；预热 1 次、计时 3 次取中位。
- 指标：每秒生成帧数（生成帧数 ÷ 生成耗时，不含加载）、首帧延迟、显存峰值、加载耗时；记录 GPU / 驱动 / CUDA / torch / 权重 sha。
- 硬件：RTX 4090 24GB、RTX 5090 32GB、A800 80GB（与 VLA 基准同三张，AutoDL 按量）。显存不够的如实记「24GB 跑不起来」，这本身就是有用的结果。
- 产出：`data/world_measurements/*.json` → 详情页「司南实测」卡。

### B. 物理考题（每月一次）

两条线：

**通用题（图 + 文字 / 图 + 镜头或键鼠）**——给可交互世界模型、通用世界模型，也给视频模型（Seedance、可灵、Veo、Wan 等，经中转站接口）做对照：

| # | 题 | 怎么算过 |
|---|---|---|
| 1 | 球滚到箱子后面，再从另一边出来 | 出来的是同一个球（颜色、大小、花纹不变），没有凭空多一个或消失 |
| 2 | 镜头向左转 90° 再转回来 | 回到起点时家具在原位、数量不变 |
| 3 | 一个人从柱子后走过 | 走出来后衣服颜色、发型不变 |
| 4 | 杯子被推到桌边掉下去 | 向下落，落地后停住或碎，不浮空、不穿过地面 |
| 5 | 球从高处落地弹起 | 每次弹起高度比上一次低 |
| 6 | 一摞 5 块积木被推倒 | 倒下后还是 5 块，不融合、不变多 |
| 7 | 往透明杯里倒水 | 水位上升；杯子没满前杯外没有水 |
| 8 | 推开一扇门 | 门绕门轴转，不平移、不变形 |
| 9 | 开灯 | 房间变亮，影子方向和灯的位置一致 |
| 10 | 镜头绕一瓶饮料转一圈（商家题） | 瓶型不变，标签上的字前后一致、能读 |
| 11 | 镜头绕一双运动鞋转一圈（商家题） | 鞋型、配色、logo 位置前后一致 |
| 12 | 镜头从店门口走进一家小店再退出来（商家题） | 货架、商品位置前后一致，没有穿墙 |
| 13 | 包装盒上印一行固定中文（商家题） | 全程字能读、不糊、不变字 |
| 14 | 手把产品从桌上拿起再放下（商家题） | 产品形状、大小不变，放回原处 |

- 起始图：我们自己用 Blender 做的简单场景（版权干净，且每题都有物理引擎算出的「标准答案」视频可并排对照）；商家题用自有拍摄的普通商品照片。
- 判定：每题按上表规则记「过 / 不过 / 看不出」，抽帧截图和完整视频全部公开，任何人可以复核；不算综合分、不排名。v1 由维护者按规则判，判定和截图一起发布；规则写死后再考虑自动判。
- 每题每模型生成 1 次（同一随机种子能固定的就固定），不挑最好的一次。

**机器人题（图 + 动作序列）**——给机器人世界模型：用各模型官方示例里的起始帧和一段固定动作（机械臂下降、夹爪闭合、抬起），看物体是否跟着夹爪走、有没有凭空消失或穿模。v2 再做，先把通用题跑通。

### 成本估算

- 开源模型：每个模型下载 + 生成 14 题，A800 约 1–2 小时（¥6–12）；15 个模型一轮约 ¥100–200。
- 视频模型对照：经中转站接口，每条 $0.1–0.5，14 题 × 6 个模型约 $10–40。
- 闭源世界模型：Marble 等按官方价；Genie 3 需要 Google AI Ultra 订阅（冰哥决定要不要开）。
